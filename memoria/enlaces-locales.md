Edu (5-nov): «pásame siempre el enlace en local para verlo».

**Why:** revisa todo desde VS Code y quiere abrir el archivo con un clic, sin buscarlo.

**How to apply:** al presentar un vídeo, foto, lámina o ficha de la cola, dar la ruta como enlace markdown relativo al repo, p. ej. [collar-nombre-piedra-9x16.mp4](marca/fotos-ia/collar-contenido/collar-nombre-piedra-9x16.mp4). Si hay varias piezas, un enlace por cada una. Ya lo pedía antes con «psame los enlaces para verlas aquí» (fotos de fichas).

**Vídeos con sonido (7-nov):** en el reproductor de VS Code a Edu **no le suena** el audio, aunque el ffmpeg de VS Code tenga AAC. Al enseñarle un vídeo con voz o música, darle el enlace igual y recordarle en una línea: clic derecho → «Revelar en el Explorador de archivos» → doble clic (reproductor de Windows).
